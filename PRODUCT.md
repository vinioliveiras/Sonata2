# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML/CSS (+ small vanilla JS), one `docs/index.html` served by GitHub Pages. No build step.

## Users

People coming from macOS or Windows who want to switch to Linux without a learning curve: they expect a desktop that looks and behaves like what they know, works on ordinary hardware, and installs without fiddling.

## Product Purpose

Sonata 2 is a complete desktop shell for Linux (not a GTK theme): login screen, menu bar, Dock, Launchpad, Search, notifications, Control Center, Files, Settings and a set of apps. Everything is animated, light and dark, and smooth on ordinary hardware. The site succeeds when a visitor installs it; starring the GitHub repo and supporting on Ko-fi come right after, in that order.

## Positioning

A whole familiar desktop on Linux in one install command, built on Wayfire + GTK 4 with no GNOME or KDE underneath. Its look comes from themes made of design tokens (the first theme follows the macOS Big Sur–Ventura layout, glass and motion; a Windows 11-style theme is planned), so a theme is a set of values, not a fork.

## Capabilities and Constraints

- Pre-alpha / alpha releases on GitHub (`vinioliveiras/sonata2`); install is one command (install.sh).
- Ships its own wallpapers (Mountains light/dark and others from Unsplash) and apps (Files, Settings, Notes, Calendar, Music, Videos, Preview, TextEdit, Terminal, Calculator, Task Manager, Disk Utility, Camera, Clock...).
- Runs on any distribution that ships Wayfire, GTK 4 and libadwaita.
- Product name is "Sonata" / "Sonata 2"; never show Apple product names on screen (credits may name real upstream projects).

## Brand Commitments

- Every user action animates — the site should feel the same.
- Light and dark, both first-class.
- Ko-fi support link: https://ko-fi.com/vinioliveira (placed early, not hidden).
- Credits section for upstream work (icon packs such as MacTahoe / apple_cursor, Wayfire, Unsplash photographers).
- Visual reference the owner picked for the site: Linear (linear.app).

## Evidence on Hand

- Real screenshots: `docs/screenshots/*.webp` (desktop, Launchpad, Control Center, Files, Settings, Notes, Task Manager, light and dark) generated by `tools/readme-shots.py`.
- Wallpapers: `sonata2/data/wallpapers`.
- No testimonials, user counts, press or benchmarks exist: never invent them.

## Product Principles

1. Familiar first: a switcher should recognise everything at a glance.
2. Show, don't claim: real screenshots and real motion over adjectives.
3. One command to start; nothing to configure after.
4. Light on hardware, smooth everywhere.

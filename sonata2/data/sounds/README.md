# Sounds

Interface sound effects (`sonata2/sounds.py`), taken unchanged from the
[freedesktop sound theme](https://www.freedesktop.org/wiki/Specifications/sound-theme-spec/)
0.8: `trash-empty`, `complete`, `camera-shutter`, `audio-volume-change`,
`dialog-warning`, `device-added`, `device-removed`, `message`, `alarm-clock-elapsed`
(Clock's alarms, `clock/alarms.py`). Authors and
licences (CC-BY / CC-BY-SA / GPL) per file in `CREDITS`.

`sonata-alarm-*.oga` (Clock's alarm sounds: Morning, Chimes, Harp, Sunrise,
Pulse) are Sonata's own, synthesized by `tools/gen-alarm-sounds.py` (no
samples), CC0.
